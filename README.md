# Local Post Studio

[简体中文](#简体中文) · [English](#english)

## 简体中文

Local Post Studio 是一个本地视频后期工作台。最早是为了整理一段采访，现在可以用来离线生成字幕、校对时间轴、转码视频，以及把相机 Log 素材转换成 Rec.709。

**Windows x64 体验版 0.2.1** 正在小范围内测。安装包通过部门 QQ 群分发。macOS 和 Linux 版本仍在规划中。

如果遇到问题，欢迎在 **Issues** 里附上软件版本、系统版本、复现步骤和实际结果。涉及私人素材时，可以用合成片段或去掉个人信息的截图来说明。

## English

Local Post Studio is a desktop workspace for local video post-production. It started as a tool for editing an interview and now supports offline transcription, subtitle timing and editing, video transcoding, and conversion from camera Log footage to Rec.709.

**Windows x64 Preview 0.2.1** is in limited testing. The installer is shared in the team’s QQ group. macOS and Linux versions are planned.

To report a problem, open an **Issue** with the app version, OS version, steps to reproduce it, and what happened. For private footage, use a synthetic clip or a screenshot with personal details removed.
